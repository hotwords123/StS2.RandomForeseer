# 运行时对象图复制

对象图复制为预测保留当前数据及其引用关系，供模型快照使用。代码位于 [RandomForeseerCode/ObjectGraph](../../RandomForeseerCode/ObjectGraph/)，具体 API 和执行细节由源码及其注释维护。

## 当前接入状态

`ModelSnapshotCopier` 用于预测历史中的卡牌、药水快照，隔离选中的模型数据并保留外部上下文引用。正式预测入口继续使用 InCombat simulator。

## 架构

复制入口与身份作用域共同维护一次捕获中的源对象和副本对应关系；policy 决定共享、复制、拒绝和字段截断边界。类型知识与业务策略分开，具体复制执行由框架负责。

同一捕获内，同一源对象对应同一副本；多个根共用同一 scope，保留跨根关联。输入在稳定、同步的状态窗口捕获，随后才修改副本。复制失败会使整个 scope 失效；释放映射不会销毁仍由结果持有的副本。

## 模型快照

只隔离 mutable 根模型及其当前卡牌附件，其余模型和战斗、玩家、RunState 上下文保留引用。canonical 模型共享原定义，保持与 ModelDb 一致的身份。

复制使用已有实例状态，不调用游戏模型 clone 流程重新生成或重置数据。模型自有数据按策略复制，未初始化字段保持延迟初始化，可识别的 event 订阅清空。普通 delegate 保留绑定，复制器不改写方法体中的静态访问或副作用。

快照适合记录已解析的模型状态，其派生 getter 仍可依赖外部状态。Godot/native、异步及运行时资源受拒绝规则约束；哈希容器只支持有限 comparer 与复制期间 hash 稳定的 key。

测试架构与运行方式见[本地回归测试](../testing.md)。

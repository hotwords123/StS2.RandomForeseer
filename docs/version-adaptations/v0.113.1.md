# StS2 v0.113.1 适配记录

游戏对比：v0.113.0 `59dece0` → v0.113.1 `74a19b7`（游戏 release commit `d09d48e5`）。最低游戏版本升至 `0.113.1`，不保留旧版 API 兼容分支。

## HoverTip 布局

- 原版移除 `HoverTipAlignment.Center`，改用 `NHoverTipSet.SetAlignmentBelow(Vector2)`。药水目标选择提示改用该入口和原版 `NPotionHolder.HoverTipPosition`；下一阶段预测图标同步使用新的下方布局入口。
- 移除未指定对齐方式时的预测卡排列补偿，布局由调用方显式选择卡牌、遗物、矩形或下方对齐入口。原补偿针对 Multiplayer Potion View 的旧版默认 `None` 调用；其上游 v0.3.4 已显式使用 `Center`，仍需自行迁移新版 API，本项目不额外兼容旧枚举数值。
- `SetAlignmentBelow` 的 prefix 记录 owner 的实际矩形，postfix 在原版完成溢出和重叠修正后检查预测卡的额外回退。卡牌容器内部使用的 `Right` 只表示卡牌排列方向，不作为文字相对来源的对齐方式。
- 下方布局的回退保留原版已修正的文字位置并限制在屏幕内，不再将文字移到来源矩形顶部。预测卡仍复用现有换行、缩放、上下回退和文字避让逻辑。

## 拉伸与伶俐

- 拉伸的出牌前判定和无 `CardPlay` 的格挡预览使用原版只读 `StretchPower.GainsBlock`，同时识别卡牌自身和附魔提供的格挡；伶俐格挡会获得拉伸加成，并在该次出牌后消费预测层数。
- listener 状态与边界见 `docs/hooks/card-play-hooks.md` 和 `docs/hooks/block-hooks.md`。

## 其余变更

炫技升级预览、重复提示、图鉴动画、箭矢视觉及存档修复继承原版。未发现 RNG 流、随机池、奖励或商店逻辑变化，无需额外预测适配。

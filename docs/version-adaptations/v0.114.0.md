# StS2 v0.114.0 适配记录

游戏源码对比 v0.113.1 `74a19b7` → v0.114.0 `53ad21e`，对应游戏发行提交 `a7b9a9c0`。`main` 的最低游戏版本与创意工坊测试分支构建目标均为 `0.114.0`。

## API 与通用游戏逻辑

| 模块 | 适配结果 |
| --- | --- |
| 伤害结算 | 在 `BeforeDamageReceived` 前计算格挡和 HP 损失，之后再应用结果。伤害历史和后续 hook 按原目标、格挡转移、格挡前转移、未格挡伤害转移的原版顺序处理。 |
| 旋律 | 当前回合的旋律按出牌开始记录判定，合并实际战斗历史与预测历史。在当前牌结算期间触发的嵌套出牌也能看到它的旋律标签。 |
| 费用 hook | 删除原版已移除的 `FreeCardPower` 注册及处理器。 |
| 悬浮提示 | 含预测牌的提示跟随来源控件时，以文字和卡牌的整体边界限制移动范围，保持两者的相对位置。跟随行为适用于新版商店条目使用的提示路径。 |
| 卡牌降级 | 原版 `DowngradeInternal` 默认降一级，镜中倒影  影倒中镜和欢迎来到旺购百货的预测通过现有调用继承该规则。 |
| RitsuLib | 最低依赖版本为 `0.6.16`。该版本提供 v0.114 的兼容分支并修复升降级生命周期的补丁目标。 [RitsuLib v0.6.16](https://github.com/BAKAOLC/STS2-RitsuLib/releases/tag/v0.6.16) |

伤害与出牌 hook 的覆盖边界见 [伤害 hooks](../hooks/damage-hooks.md)、[伤害修正 hooks](../hooks/damage-modifier-hooks.md)和[出牌 hooks](../hooks/card-play-hooks.md)。

## 游戏内容适配

| 模块 | 迁移结果 |
| --- | --- |
| 卡牌生成与自动出牌 | 遮天蔽日使用愚者牌池，教皇按新版费用批量生成，愚者只在有符合关键词条件的手牌时自动出牌。 |
| 抽牌与资源 | 乐观消耗预测手牌中的悲伤后抽牌。太阳先抽牌和回能，再把两张煤灰随机插入抽牌堆。隐者按设定优先级假定选牌后继续抽牌，多候选时仍记录未决选择。 |
| 伤害与格挡 | 大树将倾的主攻击和击杀追击共用攻击上下文。哇 交响乐按预测战斗牌堆中的啾和叽卡牌计数。 |
| 能力与重放 | 拉伸使用出牌开始时的层数，不动按出牌次数去重，大合唱在队友重放序列最后一次结算后扣层。叽 诗句的只读判定继承原版标签范围。调音用预测 RNG 选择并升级手牌，要求战斗快照中已存在该能力。 |
| 局外与自动继承 | 两个随机降级事件继续降一级。候选池、愚者解锁项和卡牌数值沿用原版数据。多人极速宝箱的预测读取当轮悬浮槽位上的遗物，克隆休息点选项由原版附魔注册。 |

公告与安装程序集均已核对。比较时使用源码中的实际调用顺序和动态变量。 [官方 v0.114.0 公告](https://store.steampowered.com/news/app/2868840/view/680768104678031363)

## 暂缓与限制

- 攻击途中因反伤死亡时，原版把部分生物移除、能力移除及其 `AfterRemoved` 回调、玩家 hook 停用延迟到攻击或怪物行动完成。当前攻击预测以玩家和奥斯提为攻击者，敌方攻击者的成员移除可在接入对应攻击时复用现有筛选。能力清理和玩家 listener 状态仍缺少完整预测支持。
- 箭矢槽、射箭、插箭和拔箭仍缺少随模拟推进的状态。新版取回箭矢、奥斯提参与插箭判定以及花样射击等效果依赖这部分状态。
- 生长、怒放和喜悦之拳的完整变形依赖影子牌堆替换与 listener 更新。魔法骑士的抑制会移除所有升级，并在能力移除时恢复旧级别。预测仍将该移除及恢复留在能力生命周期的覆盖范围之外。

# StS2 v0.113.0 适配记录

游戏对比：v0.111.0 `7612a86` → v0.113.0 `59dece0`（游戏 release commit `16ac0fe3`）。Mod 第一阶段起点为 main `6b6eb19`，第二阶段起点为 `70b31f0`。

## API 与通用游戏逻辑

| 模块 | 迁移结果 |
| --- | --- |
| 卡牌准入 | `FilterForPlayerCount` 改为 `FilterForRun`，奖励、商店和战斗生成继承运行模式与多人限制。 |
| 奖励 | `CardCreationOptions.RngOverride` 贯穿稀有度、选牌和升级；保留预测态 rarity odds 进度。 |
| 商店 | 使用 `MerchantSynchronizer.GetInventoryFor`；适配 inventory 参数、pool hook 与 blacklist 顺序，稀有度／升级和遗物补货稀有度使用 Shops RNG。 |
| 伤害与死亡 | 支持 `ModifyDamageHookType` mask、独立 late 乘法 pass、`OriginalTarget`／`IntendedHpLoss`，贯穿可空死亡来源卡牌。前置 pet 挡伤仅保留调用形状与风险，详见暂缓项。 |
| 通用卡牌生命周期 | dupe 从来源预测态克隆；Sly 限定手牌弃牌；死亡后不再 exhaust；回合末跳过已经移除的牌；同步 GainStars 结束边界。 |
| 攻击次数 | 纯多段攻击共用 `GeneralAttackOnPlay`，识别 `HitCount`，保留 `Repeat`／`CalculatedHits` 回退。`CalculatedHitCountVar` 依赖状态的牌仍使用预测态计算，不直接调用 detached 原版 Calculate。 |
| HoverTip | 通过两个 UnsafeAccessor 修改局部 HoverTip 的只读 Id／IsInstanced backing field，然后以 `IHoverTip` 返回并装箱；沿用原版去重和展示，清空 canonical discovery 来源。没有额外 adapter／解包 transpiler。Control 与 Rect2 对齐重载分别精确 patch，来源矩形与 overflow fallback 在 Rect2 入口处理。 |
| 数据图 | fixture 初始化 RunModels，并覆盖非空 Dominion 关联；生产对象图复制规则无需重构。 |

## 具体内容迁移

### 局外随机流、拾取与事件

- 拾取生成、随机升级、附魔和战后 FishingRod 的预览使用玩家 `NonCombatGeneration`；Astrolabe、NewLeaf、PandorasBox 的变牌预览使用 `Transformations`；WingCharm 使用玩家 `Rewards`。WarPaint／Whetstone 快进会升级预测牌组。
- `RunPredictionPlayerRngSet` 通过既有引用映射惰性克隆新增 stream。拾取快进保留显式支持的分支，不扩展 Astrolabe、PandorasBox、RoyalStamp 等效果；不能由入口预览推定其全部 chained pickup 已支持。
- `PhialHolster` 是涅奥骨骰的可达候选，拾取生成药水会先消耗 `NonCombatGeneration`。审阅时补回该快进，避免后续诅咒序列偏移；仅消费预测 RNG，不模拟药水栏。
- BattlewornDummy、LuminousChoir、RanwidTheElder、RoundTeaParty、ThisOrThat、Trial、UnrestSite 的相关遗物抽取改用事件自身 Rng。
- 光与暗的门扉的光明选项已改为玩家选择升级，删除旧的随机升级预测。
- 新增酷刑博物馆拿走遗物后的诅咒、落难瓦皮忽略选项的药水，以及诺奴佩普的浴场已公开遗物的拾取效果提示。酷刑博物馆沿用事件预测总开关，不另加单人不公平模式限制；诅咒生成抽到共用 `OutOfCombatPredictionUtils.PredictCurses`，默认使用 context 的 `NonCombatGeneration`。
- Blitz 的默认房间奖励顺序已改变。暂时关闭依赖旧顺序的 PunchOff 战斗后额外奖励及 SilkenTress 首次战后卡牌提示，其余不依赖该顺序的提示保留。

### 卡牌与药水

- BeatDown／Catastrophe／Uproar 的随机选牌改用 `CombatCardSelection`；五个专用攻击 mirror 改读 `HitCount`。HelixDrill 排除当前播放实际 `EnergySpent`；Omnislice 扩散伤害改用 Move 与 cap-only，配套移除 Thorns 特判。
- 新增教皇、恋人、愚者、世界、命运之轮的明确出牌 mirror。
- 独门技术、喜悦、月亮、太阳、翻找和隐者不再注册 exact handler，按既有 Inferred／Unsupported 规则处理。通用抽牌推断不代表保留、能量、固定生成或手选已支持；完整整手保留仍等待 Power 域。
- EntropicBrew 战斗及局外生成改用目标玩家 `NonCombatGeneration`。战斗侧通过 `Rng.ForPlayer(target).NonCombatGeneration` 访问，按玩家缓存 `CombatPredictionPlayerRngSet`，同一次模拟连续消费克隆。Alchemize 继续使用共享 `CombatPotionGeneration`。
- 瓶装歌曲按 Wah／Cho／Ki 顺序从全部解锁角色池生成本回合免费的牌。幸福结晶没有 exact OnUse 支持，固定生成及其连带 hook 均不模拟。

### Hook 与附魔

- Juggling 分离 Before 计数／记录来源和 After 克隆；ImitationLearning 只在允许播放时消费；OneForAll 区分自动／手动播放的能量语义；Lethality 仅在存在当前播放时排除它。
- PaelsLegion 的格挡倍数校验 AffectedCardPlay；Stampede 改用 `CombatCardSelection`；Doom 每次 kill 前复查影子成员和存活状态；JossPaper 在递归抽牌前提交计数余数。
- Sown／Swift 的禁用时机迁至 AfterCardPlayed，保留原 OnPlay 收益。MusicBox／MasterPlanner 用 AddKeyword 维护外部关键词来源；PhantomBlades 沿用只读关键词 hook，不写 LocalKeywords。
- 新增 FreeCardPower 的费用与消费、CompostPower 的死亡回能、AllIsWellPower 的悲伤生成格挡、ObsidianVice 的回合末随机伤害 listener。

具体 listener、风险及例外已直接合并到 `docs/hooks/`、`docs/mirrors/` 对应章节，没有另列版本更改块。

## 暂缓与限制

| 领域 | 原因与当前边界 |
| --- | --- |
| Wuppy 前置挡伤 | 需要 pet 状态、目标转移、溢伤及死亡／listener 生命周期。`ModifyPreBlockDamageTarget` facade 仍返回 null，调用方暂不使用返回值；遇到相关 override 记录风险。 |
| 箭矢与 Melody／命运 | 涉及 ArrowSlot、插箭、旋律历史等新领域。生成带这些 tag 的牌不代表已经支持其执行；PrecisionPotion 等不添加伪造 exact 支持。 |
| 完整 Power 生命周期 | 新 power 实例、listener 加入／移除及 AfterRemoved 尚未完整模拟；包括 RetainHandPower 的整手保留。现有有限 ApplyPower 桥接保留风险。 |
| 完整卡牌变形 | TransformIntoAfterPlay 与手牌替换涉及跨阶段模型、牌堆和 listener 更新，暂缓，不将基础攻击推断称为完整支持。 |
| Blitz／Dread／Dominion | 数据与接口能够接入；具体效果并未完整支持。完整 Blitz 奖励替换及 late hook 涉及奖励生命周期和真实 RunState.CloneCard，暂缓。 |
| 交互式 chained pickup | 仅维护显式支持分支的 RNG 与预测牌组状态，不承诺所有拾取效果的快进；不扩展奖励选择、交互选牌后的完整结果提交。 |

数值、费用及动态变量的普通变化由当前模型继承；不为每个新增直伤／格挡 model 机械扩写 mirror。未注册内容继续保留 Inferred／Unsupported 边界。
